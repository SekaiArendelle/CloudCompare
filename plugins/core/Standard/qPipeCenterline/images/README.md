# Plugin Icon

This directory should contain the plugin icon file named `qPipeCenterline.png`.

The icon should be:
- Format: PNG
- Size: 32x32 or 64x64 pixels
- Transparent background
- Representing pipe centerline extraction functionality

You can create an icon showing:
- A pipe or tube shape
- A centerline running through the pipe
- Different colors for the pipe and centerline
- Optional branching representation

Example icon concepts:
1. A cylindrical pipe with a bright centerline
2. Multiple connected pipe segments with centerlines
3. A stylized "CL" (CenterLine) logo with pipe imagery
